# GKD_First_Test

基于 [AIsouler/GKD_subscription](https://github.com/AIsouler/GKD_subscription) 的个人自用 GKD 订阅。

## 由来

规则大部分参考自 [AIsouler 前辈的仓库](https://github.com/AIsouler/GKD_subscription)。本人不会写代码，所有的规则都是把广告页面一步步截图丢给 DeepSeek，让它帮我生成对应的关闭规则。

在此衷心感谢 AIsouler 前辈的大力付出与贡献。

由于前辈的仓库已停止维护，后续规则均为自用场景下补充编写，随缘更新。
